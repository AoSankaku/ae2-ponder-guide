# AE2 with Ponder

Learn AE2 through 40 animated, three-dimensional scenes. Start from the beginning or choose a topic below. Every topic opens the same course at the selected scene.

<CommandLink command="/ae2ponder">Watch from the beginning</CommandLink>

## How to watch

Open the guide while playing in a world, then click a topic. Use Ponder's left and right navigation buttons to move between scenes. The return arrow in the lower-left corner brings you back to this guide page.

The scenes explain connections, item flows, and common mistakes step by step. You can pause playback to inspect a setup before continuing.
