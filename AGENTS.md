# Localization maintenance

This project supports all 15 languages in `src/main/translations/languages.json`:
Japanese, English, Hindi, Traditional Chinese (Hong Kong and Taiwan), Simplified Chinese,
Russian, Portuguese (Brazil and Portugal), Spanish, German, Czech, Polish, Malay, and Romanian.

Every user-visible addition or change must be reviewed and updated in **all 15 languages**
in the same change. This includes subtitles, lesson titles and summaries, catalogue/search UI,
chapters, Ponder/GuideME controls, and the ME Guide page. Do not ship English fallback for a supported
language. Keep Hong Kong/Taiwan Chinese and Brazil/Portugal Portuguese distinct.

Use Create/Ponder's tone in each language. Japanese explanatory sentences use polite
です・ます style; instructions use forms such as してください. Titles and short controls
may stay as natural nouns or short action labels. Follow the native address conventions
in other languages (for example Czech polite plural and European Portuguese tu), rather
than making every language formal. Keep meaning, conditions, numbers and terminology intact.
Unsupported locales and missing runtime translations fall back to English (`en_us`),
including the default ME Guide page. Complete the supported languages instead of relying
on that fallback for them.

- English/Japanese lesson text lives in `src/main/resources/assets/ae2ponder/guide/lessons.json`.
  Optional add-on lesson text lives in the adjacent `addons.json`; translate it in all 15 languages too.
- English/Japanese UI, chapters, Ponder/GuideME controls and guide introduction live in `src/main/templates/lang`.
- The other 13 complete language bundles live in `src/main/translations/<locale>.json`.
- `python tools/localization.py source` exports the current English keys and `_source_hash`
  to the ignored `.local/localization/source.json` for translation work.
- After reviewing **every changed source string** in each language, update its translations
  and `_source_hash`. Never refresh a hash merely to bypass the stale-translation check.
- `src/main/translations/source-review.json` records the English/Japanese review against
  the same hash. Review and update both records too; changing one original language must
  not silently leave the other original language behind.
- Preserve placeholders, technical constraints, numbers, item identities, and command IDs.
- Run `python tools/localization.py check` and the relevant Gradle build. Missing keys,
  empty text, invalid placeholders and stale source hashes must fail verification.
- Language JSON and all 15 ME Guide pages are generated by `gradle/localization.gradle`.
  Do not maintain additional copies in `src/main/resources` or edit generated files.

Verification should inspect non-Latin text and catalogue searches when localization code
changes. Prefer one hidden client and targeted language checks over repeated Minecraft startups.

All supported add-ons and their required dependencies are included in development/test launches.
Verify both the default launch and `-PwithoutAddons` after changing optional integration.
Keep add-ons optional in the distributed mod and exclude absent lessons from the catalogue,
Ponder registration/course, and GuideME rendering/search. Do not reference add-on Java classes.
